# 📝 Todo 리스트 API

by ChatGPT

<br>

## 실습 내용

- 주제는 간단한 Todo 리스트 API
- 사용자는 할 일을 추가, 조회, 상태 변경(미완료, 완료), 삭제할 수 있다.
- 해당 실습에서는 위의 문제 설명과 아래의 요구사항을 만족하는 REST API를 자유롭게 정의하고, TDD 방식으로 구현하는 것

<br>

## 요구사항

- 할 일 추가하기, 할 일 목록 조회하기, 할 일 완료로 표시하기, 완료된 할 일 삭제 API를 구현한다.
- Content-type 응답 형태는 application/json(JSON) 형식을 사용한다.
- 각 기능 및 제약사항에 대한 개발을 TDD, 단위테스트를 기반으로 진행해야 한다.

<br>

## API 명세서
| **API**      | **HTTP Method** | **URI**                          | **Request** | **Response**                                               |
|--------------|-----------------| -------------------------------- |-------------| ---------------------------------------------------------- |
| 할 일 추가하기     | POST            | /api/todos                       | - 제목<br>- 설명 | - 할 일 ID<br>- 제목<br>- 설명<br>- 완료 상태<br>- 생성 일시 |
| 할 일 목록 조회하기  | GET             | /api/todos                       | x           | {할 일 ID, 제목, 설명, 완료 상태, 생성 일시} 리스트  |
| 할 일 상태 변경    | PATCH           | /api/todos/{todoId}     | - 완료 상태     | - 할 일 ID<br>- 제목<br>- 설명<br>- 완료 상태<br>- 생성 일시 |
| 할 일 삭제하기     | DELETE          | /api/todos/{todoId}              | x           | x                                                          |

<br>
